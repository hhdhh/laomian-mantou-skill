# 老面馒头技能治理（laomian-mantou）

> 核心隐喻：技能不是一次性写完的静态文件，而是**活的面团**。
> 每次使用中产生的经验是"喂养"，攒够同类经验就"蒸馏"进正式文本，
> 膨胀过度要"兑碱"修剪，每代大改后"留种"防退化。

## 三件套结构

每个被治理的技能目录下：

```
skills/<name>/
├── SKILL.md      # 成品馒头（发酵后的正式文本）
├── starter.md    # 老面/种子：<30行最小可传承内核
└── ferment.md    # 发酵日志：追加式经验池（只追加，不覆盖）
```

- **starter.md** 内容 = 一句话定位 + 核心流程≤5步 + 红线≤3条 + 已知坑≤3条。技能 SKILL.md 被改烂/压缩丢失/漂移时，从种子恢复重写。
- **ferment.md** 每条经验一行，格式：`[YYYY-MM-DD] 场景 | 教训一句话`。**禁止覆盖已有条目，只能追加。**

## 核心流程

### 1. 喂养（喂老面）
技能实际使用中踩坑/被用户纠正/发现新工作流时：
1. 确认经验属于**本技能触发范围内**（防杂菌污染，见反例）
2. 追加一条到该技能 `ferment.md`
3. 不立即改 SKILL.md —— 单次经验可能是偶发，让它继续发酵

### 2. 蒸馏（蒸馒头）
`ferment.md` 中**同类经验 ≥3 条**（同一根因或同一主题）时触发：

**🔴 CHECKPOINT：蒸馏会修改正式 SKILL.md，patch 前向用户简报"哪 3 条 → 合并成什么规则"再动手；批量蒸馏（≥2 个主题）必须等确认。**

1. 把 3+ 条合并成 **1 条**通用规则（教训要泛化为"如果 X → 做 Y"）
2. 用 `patch` 写入 SKILL.md 的对应章节；无对应章节则新增
3. 蒸馏后**在 ferment.md 对应条目后标记 `[已蒸馏→SKILL.md]`**，保留原文不删
4. 过兑碱门（见下）

### 3. 兑碱门（防膨胀，每次改 SKILL.md 必过）
修改后逐项检查，任一命中即修剪：
- SKILL.md > 300 行 → 合并同类条目、删空话段
- frontmatter description > 500 字符或触发词过宽 → 收窄
- 出现"灵活把握/视情况而定/根据情况判断"类软化措辞 ≥2 处 → 改成明确分支
- 与 darwin-skill 9 维度 rubric 冲突（无失败分支、无反例清单）→ 补

### 4. 醒面（验证后定稿）
改完不立即宣布完成：跑 1-2 个典型任务验证新规则真的有用（或用 darwin-skill 评分不降）才保留，否则回滚。

### 5. 留种（每代更新）
每次蒸馏进 SKILL.md 后同步重写 `starter.md`（仍 <30 行）。留种时对照技能的**原始目标**自问：这个种子能独立长回当前能力吗？不能 → 种子写漏了本质。

## 失败模式（patch/文件操作分支）

| 失败 | 处理 |
|---|---|
| patch SKILL.md 失败（模糊匹配不中） | 重读原文获取当前精确内容再试；同一处失败 2 次后整文件 write_file 重写，禁止第 3 次 patch |
| ferment.md 被误删 | 丢失即接受（无备份义务）；下次经验重新喂养，不编造历史条目回填 |
| ferment.md 追加时写坏格式 | 修复格式后原条目保留，不删除 |
| starter.md 与 SKILL.md 漂移（能力不一致） | 以 SKILL.md 为准重写 starter；蒸馏流程第 5 步兜底 |
| 蒸馏触发但 3 条实为异根因 | 停止合并，拆回 ferment.md 继续发酵，等真同类的第 3 条 |

## 反例与黑名单

- ❌ **面酸了**：把单次偶发经验直接写进 SKILL.md（不经发酵攒 3 条）→ 技能膨胀、规则互相打架。单次经验只进 ferment.md。
- ❌ **传代退化**：starter.md 多代复制不回炉，丢失技能本质 → 每次留种重写而非追加，并对照原始目标。
- ❌ **杂菌污染**：把其他技能范围内的事喂进本技能 ferment.md → 喂养前先确认"这事归这个技能管吗"。
- ❌ **覆盖发酵日志**：ferment.md 是审计记录，删改 = 丢证据；蒸馏只做标记不删原文。
- ❌ **蒸馏后不留种**：SKILL.md 更新而 starter.md 不更新 → 下一代恢复点过时。

## 与相邻技能的分工

- **fluid-memory**：管"记忆"的遗忘衰减 → 老面管"技能"的生长方式
- **darwin-skill**：管质量评分与棘轮保留（醒面阶段可调用它验收）→ 老面管喂养与蒸馏
- **skill_manage**：是落盘工具 → 老面是流程协议，告诉它何时写、写多少、写完留什么

## 触发词速查

| 用户说 | 动作 |
|---|---|
| 喂老面 / 记个经验 | 喂养：追加 ferment.md |
| 蒸馒头 / 蒸馏 | 蒸馏：3 条同类合并进 SKILL.md + 兑碱门 |
| 留种 | 重写 starter.md |
| 技能酸了 / 膨胀了 | 兑碱门单项检查 + 修剪 |
| 技能坏了 / 恢复 | 从 starter.md 恢复重写 SKILL.md |
