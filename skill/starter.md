# starter.md — 老面种子（laomian-mantou）

> 种子目标：技能腐化/漂移后，仅凭本文件能重写出完整 SKILL.md。

## 一句话定位
模仿老面馒头原理治理技能生长：四问喂养（含查重）、经验发酵、蒸馏即备份、防膨胀、醒面验收（棘轮）、留种+索引同步、六查巡检归档。

## 核心流程（5 步）
1. 喂养：先过四问（0查重 grep ferment 已有条目→不追加只补注日期 / 1归我管吗 / 2可泛化吗 / 3能写成如果X→做Y吗）→ 追加 ferment.md + 读回确认落盘（审批积压则提醒批准）
2. 蒸馏：同类 ≥3 条 → 备份先行（.bak+md5，无备份不蒸馏）→ 🔴CHECKPOINT 简报 → 合并 1 条 patch 进 SKILL.md → 条目标记[已蒸馏]+补 test-prompt（规则与证据同生）
3. 兑碱门：SKILL.md >300 行 / description >500 字符 / 软化措辞 → 修剪
4. 醒面（档位化）：轻量档=<5 行读回量化；达尔文档=验收器前后评分（接口可替换），棘轮只留提分（降分→回滚+退回发酵）
5. 留种：read_file 后 write_file 重写 starter（<30 行）+ 定位/触发变了才更新共享索引

## 闻酸味巡检（只读六查，结果归档 patrol-log.md）
超长 / ferment 积压 / starter 漂移 / 审批积压 / 索引脱链 / 待补条目 → 报告用户，不擅自蒸馏（CHECKPOINT）。可走 cron。

## 失败模式（关键 4 条）
- patch 失败 → 重读原文再试，2 次不中改 write_file 整写，禁第 3 次
- ferment.md 被删 → 接受损失重新喂养，不编造回填
- 3 条实为异根因 → 拆回发酵，不硬合并
- 验收器不可用 → 降轻量档，ferment.md 追加"醒面降级待补"条目

## 红线（3 条）
- 单次经验不直接进 SKILL.md（防面酸）
- ferment.md 只追加不删改（是审计记录）
- 四问不过不喂（防杂菌/防重复）
