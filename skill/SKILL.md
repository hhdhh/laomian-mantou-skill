# 老面馒头技能治理（laomian-mantou）

> 核心隐喻：技能不是一次性写完的静态文件，而是**活的面团**。
> 每次使用中产生的经验是"喂养"，攒够同类经验就"蒸馏"进正式文本，
> 膨胀过度要"兑碱"修剪，每代大改后"留种"防退化。

## 三件套结构

每个被治理的技能目录下：

```
skills/<name>/
├── SKILL.md      # 成品馒头（发酵后的正式文本）
├── starter.md    # 老面/种子：<30行最小可传承内核
└── ferment.md    # 发酵日志：追加式经验池（只追加，不覆盖）
```

- **starter.md** 内容 = 一句话定位 + 核心流程≤5步 + 红线≤3条 + 已知坑≤3条。技能 SKILL.md 被改烂/压缩丢失/漂移时，从种子恢复重写。
- **ferment.md** 每条经验一行，格式：`[YYYY-MM-DD] 场景 | 教训一句话`。**禁止覆盖已有条目，只能追加。**

## 核心流程

### 1. 喂养（喂老面）
技能实际使用中踩坑/被用户纠正/发现新工作流时，先过**杂菌三问**：

1. 这事归这个技能管吗？（不属于触发范围 → 不喂，找对技能或放弃）
2. 是单次偶发还是可泛化？（连场景都复述不清楚 → 暂不喂）
3. 教训能写成"如果 X → 做 Y"吗？（写不成因果句 → 先攒着，想清楚再喂）

三问全过才：
1. 追加一条到该技能 `ferment.md`
2. **读回确认落盘**（防审批队列静默丢失）：重新读 ferment.md 尾行核对条目在；若 Hermes 写审批队列（`~/.hermes/pending/skill*/`）有本技能积压 → 提醒用户批准，不重复追加
3. 不立即改 SKILL.md —— 单次经验可能是偶发，让它继续发酵

### 2. 蒸馏（蒸馒头）
`ferment.md` 中**同类经验 ≥3 条**（同一根因或同一主题）时触发：

**🔴 CHECKPOINT：蒸馏会修改正式 SKILL.md，patch 前向用户简报"哪 3 条 → 合并成什么规则"再动手；批量蒸馏（≥2 个主题）必须等确认。**

1. 把 3+ 条合并成 **1 条**通用规则（教训要泛化为"如果 X → 做 Y"）
2. 用 `patch` 写入 SKILL.md 的对应章节；无对应章节则新增
3. 蒸馏后**在 ferment.md 对应条目后标记 `[已蒸馏→SKILL.md]`**，保留原文不删
4. 过兑碱门（见下）

### 3. 兑碱门（防膨胀，每次改 SKILL.md 必过）
逐项检查，任一命中即修剪：
- SKILL.md > 300 行 → 合并同类条目、删空话段
- frontmatter description > 500 字符或触发词过宽 → 收窄
- 出现"灵活把握/视情况而定/根据情况判断"类软化措辞 ≥2 处 → 改成明确分支
- 与 darwin-skill 9 维度 rubric 冲突（无失败分支、无反例清单）→ 补

### 4. 醒面（验证后定稿，档位化）

改完不立即宣布完成。按改动风险选档位：

| 档位 | 适用 | 验证方式 |
|---|---|---|
| 轻量档 | 兑碱门单项修剪、格式修复、<5 行改动 | 兑碱门量化指标读回（行数/description/软化措辞扫描） |
| 达尔文档 | 蒸馏新增规则/新章节、结构性改写 | 跑 darwin-skill 完整验收 |

**达尔文档协议**（默认验收器 darwin-skill，可替换）：
1. 改前取基线：读验收器的最近记录（darwin 读 `darwin-skill/results.tsv`），无则现场基线评分
2. 改后 9 维复评：结构维度主 agent 自评；效果维度 spawn 独立子 agent 盲测（with-skill vs baseline 跑 test-prompts.json），子代理不可用则干跑并标注 `dry_run`
3. **棘轮**：新总分 > 基线 → keep 并写入验收记录（eval_mode 标 `laomian`）；新总分 ≤ 基线 → 回滚备份文件，本次蒸馏作废、经验退回 ferment.md 继续发酵
4. 干跑（dry_run）比例过高时结果只作参考，须在下次真实任务补验证

**验收器接口**（任何满足以下三点的评估器均可替代 darwin-skill）：①能对 SKILL.md 产出量化总分；②支持同一测试集前后对比；③有可追加的结果日志。替换时只需把协议中的取基线/写记录两步指向新评估器的日志文件。

**降级路径**：darwin-skill 不可用（子代理超时/环境限制）→ 退轻量档读回验证，同时在 ferment.md 追加一条 `[YYYY-MM-DD] 醒面降级 | 本次改动未过真实评估，待补`，下次蒸馏前先补验该条。

### 5. 留种（每代更新）
每次蒸馏进 SKILL.md 后同步重写 `starter.md`（仍 <30 行）。留种时对照技能的**原始目标**自问：这个种子能独立长回当前能力吗？不能 → 种子写漏了本质。

**索引同步（留种后顺手做）**：蒸馏若改变了技能定位/触发范围，更新本机各技能索引中该技能那一行摘要（如 `~/.codex/shared/skills-index.md` 等共享侧索引），保证"先查索引再读全文"的检索链不过时。共享侧索引是生成物：只改摘要行，不手工重排。

## 闻酸味巡检（腐坏检测，被动+主动）

「技能酸了」可被动触发，也可主动巡检。三条量化检测（只读，不改文件）：

```bash
# ① 超长：SKILL.md > 300 行的技能
find ~/.hermes/skills -name SKILL.md -exec awk 'END{if(NR>300) print FILENAME": "NR"行"}' {} +
# ② 积压：ferment.md 有未蒸馏条目的技能（有 ferment.md 且非全行含[已蒸馏]）
for f in ~/.hermes/skills/*/ferment.md; do n=$(grep -cv '已蒸馏' "$f" 2>/dev/null || true); [ "${n:-0}" -gt 0 ] && echo "$f: ${n}条待蒸馏"; done
# ③ 漂移：starter.md 缺失或 >30 行
for f in ~/.hermes/skills/*/starter.md; do n=$(wc -l < "$f"); [ "$n" -gt 30 ] && echo "$f: ${n}行超种子上限"; done
# ④ 审批积压：写审批队列里有技能相关待批操作
ls ~/.hermes/pending/skill*/*.json 2>/dev/null | head -5
# ⑤ 索引脱链：技能存在但共享索引里没有
for s in ~/.hermes/skills/*/; do n=$(basename "$s"); grep -q "\*\*$n\b" ~/.codex/shared/skills-index.md 2>/dev/null || echo "索引缺: $n"; done | head -10
```

巡检发现积压 → 报告用户"X 技能攒了 N 条经验待蒸馏"，**不擅自蒸馏**（蒸馏有 CHECKPOINT）。定期巡检走 cron（hermes-cron-ops），报告纯只读。

## 失败模式（patch/文件操作分支）

| 失败 | 处理 |
|---|---|
| patch SKILL.md 失败（模糊匹配不中） | 重读原文获取当前精确内容再试；同一处失败 2 次后整文件 write_file 重写，禁止第 3 次 patch |
| ferment.md 被误删 | 丢失即接受（无备份义务）；下次经验重新喂养，不编造历史条目回填 |
| ferment.md 追加时写坏格式 | 修复格式后原条目保留，不删除 |
| starter.md 与 SKILL.md 漂移（能力不一致） | 以 SKILL.md 为准重写 starter；蒸馏流程第 5 步兜底 |
| 蒸馏触发但 3 条实为异根因 | 停止合并，拆回 ferment.md 继续发酵，等真同类的第 3 条 |

## 反例与黑名单

- ❌ **面酸了**：把单次偶发经验直接写进 SKILL.md（不经发酵攒 3 条）→ 技能膨胀、规则互相打架。单次经验只进 ferment.md。
- ❌ **传代退化**：starter.md 多代复制不回炉，丢失技能本质 → 每次留种重写而非追加，并对照原始目标。
- ❌ **杂菌污染**：把其他技能范围内的事喂进本技能 ferment.md → 喂养前先确认"这事归这个技能管吗"。
- ❌ **覆盖发酵日志**：ferment.md 是审计记录，删改 = 丢证据；蒸馏只做标记不删原文。
- ❌ **蒸馏后不留种**：SKILL.md 更新而 starter.md 不更新 → 下一代恢复点过时。

## 与相邻技能的分工

- **fluid-memory**：管"记忆"的遗忘衰减 → 老面管"技能"的生长方式
- **darwin-skill**：管质量评分与棘轮保留（醒面阶段可调用它验收）→ 老面管喂养与蒸馏
- **skill_manage**：是落盘工具 → 老面是流程协议，告诉它何时写、写多少、写完留什么

## 触发词速查

| 用户说 | 动作 |
|---|---|
| 喂老面 / 记个经验 | 喂养：追加 ferment.md |
| 蒸馒头 / 蒸馏 | 蒸馏：3 条同类合并进 SKILL.md + 兑碱门 |
| 留种 | 重写 starter.md |
| 技能酸了 / 膨胀了 | 兑碱门单项检查 + 修剪 |
| 技能坏了 / 恢复 | 从 starter.md 恢复重写 SKILL.md |

## 与 darwin-skill 的集成（醒面验收器）

醒面档位化后，darwin-skill 是"达尔文档"的验收器：蒸馏的改动进 SKILL.md 前后各评一次，棘轮只保留提分改动，降分即回滚。两技能各管一段——老面管**生长**（喂养/蒸馏/防膨胀/留种），达尔文管**验收**（盲测/棘轮/评分卡）。若 darwin-skill 未安装，醒面自动降级为轻量档（见降级路径）。
