# starter.md — 老面种子（laomian-mantou）

> 种子目标：技能腐化/漂移后，仅凭本文件能重写出完整 SKILL.md。

## 一句话定位
模仿老面馒头原理治理技能生长：杂菌三问喂养、经验发酵、蒸馏、防膨胀、醒面验收（棘轮）、留种+索引同步、闻酸味巡检（含审批积压/索引脱链）。

## 核心流程（5 步）
1. 喂养：先过杂菌三问（归我管吗/可泛化吗/能写成如果X→做Y吗）→ 追加一行进 ferment.md + 读回确认落盘（审批队列有积压则提醒批准，不重复追加）
2. 蒸馏：同类经验 ≥3 条 → 🔴CHECKPOINT 简报后合并成 1 条规则 patch 进 SKILL.md，原条目标记[已蒸馏]
3. 兑碱门：SKILL.md >300 行 / description >500 字符 / 软化措辞 → 修剪
4. 醒面（档位化）：轻量档=<5 行改动读回量化指标；达尔文档=蒸馏/结构改动，验收器前后评分（默认 darwin，接口可替换：量化总分+前后对比+结果日志），棘轮只留提分改动（降分→回滚+经验退回发酵）
5. 留种：重写 starter.md（<30 行）+ 定位/触发变了才更新共享索引摘要行（如 ~/.codex/shared/skills-index.md）

## 闻酸味巡检（只读五查）
超长>300行 / ferment 未蒸馏积压 / starter 缺失或>30行 / 审批队列 skill* 积压 / 技能存在但共享索引缺条目 → 报告用户，不擅自蒸馏（CHECKPOINT）。可走 cron。

## 失败模式（关键 4 条）
- patch 失败 → 重读原文再试，2 次不中改 write_file 整写，禁第 3 次
- ferment.md 被删 → 接受损失重新喂养，不编造回填
- 3 条实为异根因 → 拆回发酵，不硬合并
- 验收器不可用 → 降轻量档，ferment.md 追加"醒面降级待补"条目

## 红线（3 条）
- 单次经验不直接进 SKILL.md（防面酸）
- ferment.md 只追加不删改（是审计记录）
- 三问不过不喂（防杂菌）
